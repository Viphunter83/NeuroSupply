# Руководство Пользователя: Доступ к Системе и Управление Ролями (NeuroSupply)

Данное руководство объясняет, как получить доступ к веб-приложению (Telegram WebApp), как назначить себе и другим сотрудникам права Администратора или Менеджера, а также как поддерживать подключение (Cloudflare локально).

---

## 1. Подключение и запуск приложения (Настройка Cloudflare)

Так как ваш сервер в настоящий момент запущен локально на вашем устройстве, доступ из внешнего интернета (от серверов Telegram) обеспечивается через туннель Cloudflare. 

**Важно:** Ссылки вида `trycloudflare.com` живут недолго (если не привязан постоянный домен). Если вы перезагружали компьютер или останавливали Docker, ссылка меняется, и Telegram Bot перестает открывать WebApp.

### Как обновить туннель
Если приложение не открывается (белый экран или ошибка в Telegram), выполните следующее в терминале корня проекта (`/Users/apple/NeuroSupply`):
```bash
# 1. Перезапустить туннель
docker restart neurosupply_tunnel

# 2. Узнать новую ссылку
docker logs neurosupply_tunnel 2>&1 | grep "trycloudflare.com" | tail -n 1
```
Вы увидите строку вида `https://nova-hundreds-her-peoples.trycloudflare.com`.

### Как применить новую ссылку
1. Откройте файл `.env`.
2. Замените значение `WEBAPP_URL=` на вашу новую ссылку из предыдущего шага.
3. Перезапустите контейнеры с полным пересозданием, чтобы бот и бэкенд точно подхватили новый URL:
```bash
docker-compose up -d --force-recreate bot app
```
После этого кнопки в боте снова начнут открывать работающее приложение.

## 2. Управление ролями и доступ

По умолчанию, когда новый человек впервые нажимает `/start` в боте NeuroSupply, система регистрирует его в базе данных и выдает начальную роль **COOK** (Повар). 
Повар видит только процесс заявки ингредиентов текущего ресторана.

### Текущие Роли в системе
- `COOK` (Повар) — Видит только процесс заявки ингредиентов текущего ресторана.
- `MANAGER` (Менеджер) — Имеет доступ к Дашборду (аналитика), плану заготовок, а также процессам повара.
- `ADMIN` (Администратор/Владелец) — Имеет полный доступ (в т.ч. к кнопке `/report` в Telegram и расширенному дашборду менеджера).

### Как выдать себе или сотруднику права ADMIN / MANAGER
Так как административной панели (UI) для управления ролями пока нет (это следующий этап), назначение прав происходит напрямую через базу данных. Изменения применяются мгновенно.

**Способ 1 (Быстрый): Выдать статус всем пользователям сразу**
Если вы тестируете систему одни:
```bash
docker exec neurosupply_db psql -U apple -d neurosupply -c "UPDATE users SET role = 'ADMIN';"
```

**Способ 2: Выдать права конкретному пользователю по Telegram ID**
1. Откройте бота: [@getmyid_bot](https://t.me/getmyid_bot) (или аналог), чтобы узнать ваш `telegram_id` (например, `45053735`).
2. Введите команду в терминал на вашем Mac, подставив ваш ID:
```bash
docker exec neurosupply_db psql -U apple -d neurosupply -c "UPDATE users SET role = 'ADMIN' WHERE telegram_id = ВАШ_ТЕЛЕГРАМ_ID;"
```

*После обновления статуса в БД, просто перезайдите в меню бота (отправьте `/start`) — у вас обновится клавиатура и станут доступны кнопки "Дашборд Менеджера" и "Отчет (Админ)".*

*(Примечание: В рамках этого запуска я уже выдал вашему текущему Telegram аккаунту статус ADMIN в базе данных, поэтому приложение и кнопки дашборда должны заработать сразу с полным доступом).*
