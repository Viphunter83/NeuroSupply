# Руководство по доступу и ролям (NeuroSupply)

Данный документ описывает, как получить доступ к системе, управлять ролями и решать типичные проблемы с подключением.

## 1. Доступ через Telegram Бот

Основной точкой входа является Telegram бот. 

1. **Запуск**: Найдите бота в Telegram и отправьте команду `/start`.
2. **Веб-приложение**: Нажмите кнопку «Открыть приложение» или «Заказы на утверждение».
3. **Обновление**: Если приложение загружает старую версию, попробуйте перезапустить бота или очистить кэш Telegram (Настройки -> Данные и память -> Использование памяти -> Очистить кэш).

## 2. Роли и уровни доступа

В системе существует три основные роли:

- **COOK (Повар)**: 
  - Видит список товаров для инвентаризации.
  - Вводит фактические остатки и комментарии.
  - Может добавлять внеплановые товары («Доп. заказ»).
  - После подтверждения заказ уходит на проверку менеджеру.

- **MANAGER (Менеджер)**:
  - Доступен через кнопку «Заказы на утверждение» (`?view=manager`).
  - Видит дашборд с графиками и таблицу заготовок.
  - Проверяет заказы, подтвержденные поварами, и нажимает «Утвердить».

- **ADMIN (Администратор)**:
  - Имеет полный доступ ко всем функциям.
  - Может принудительно запускать расчеты и изменять настройки ресторанов.

## 3. Техническое обслуживание (Cloudflare)

Система работает через туннель Cloudflare. Если приложение не открывается (белый экран или ошибка 502):

1. Проверьте статус контейнера туннеля: `docker logs neurosupply_tunnel`.
2. Убедитесь, что URL в файле `.env` (`WEBAPP_URL`) совпадает с актуальным адресом из логов туннеля.
3. После обновления `.env` выполните: `docker-compose up -d --force-recreate bot app`.

## 4. Управление ролями (SQL)

Если вам нужно изменить роль пользователя вручную через базу данных:

```bash
docker exec neurosupply_db psql -U apple -d neurosupply -c "UPDATE users SET role = 'ADMIN' WHERE telegram_id = 'ВАШ_ID';"
```
