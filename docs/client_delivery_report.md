# Отчет о сдаче проекта: NeuroSupply (v0.8.0)

## 1. Основные достижения
Система NeuroSupply переведена в стадию готовности к промышленной эксплуатации. Основные вехи:

*   **Интеллектуальный расчет заказов:** AI-движок (v2) на базе линейной регрессии анализирует историю продаж из iiko и автоматически формирует черновик заказа, минимизируя списания и «человеческий фактор».
*   **Контроль аномалий:** Система выявляет резкие отклонения в закупках и информирует менеджера.
*   **Независимость от Telegram:** Создано полноценное Web-приложение (PWA) на базе Next.js, которое работает автономно и не зависит от доступности серверов Telegram в РФ.
*   **Локализация:** Внедрена полная поддержка вьетнамского языка для линейного персонала (поваров), переведено более 1000 позиций номенклатуры.
*   **Гибридная схема:** Менеджеры могут управлять планами продаж через привычные Google Таблицы, а данные мгновенно синхронизируются с БД.

## 2. Инструкция по проверке функционала (Step-by-Step)

Для приемки работ рекомендуется пройти по следующему сценарию:

### Шаг 1: Веб-Дашборд (Интерфейс Менеджера)
1.  Откройте URL: `https://nova-hundreds-her-peoples.trycloudflare.com` (или актуальный туннель).
2.  Перейдите в раздел **Analytics/Forecast**. Убедитесь, что график показывает сравнение "План vs Факт".
3.  Проверьте раздел **Stock**. Список товаров должен подгружаться из iiko с актуальными остатками.

### Шаг 2: Создание и подтверждение заказа (Путь Повара)
1.  Откройте Telegram-бот или WebApp в режиме повара.
2.  Нажмите кнопку "Создать заявку". Система должна автоматически предложить список продуктов на основе AI-прогноза.
3.  Измените количество у 1-2 позиций и нажмите "Подтвердить".
4.  Статус заказа в базе данных должен измениться на `VERIFIED_BY_COOK`.

### Шаг 3: Одобрение и экспорт (Путь Менеджера)
1.  Вернитесь в Веб-Дашборд, раздел **Orders**.
2.  Найдите созданный заказ. Нажмите "Approve" (Одобрить).
3.  Нажмите кнопку **Export to Excel**. Скачайте файл и проверьте корректность позиций.
4.  Проверьте Google Таблицу (вкладка 4. DRAFT ORDER) — данные должны автоматически экспортироваться туда.

## 3. Инструкции по установке PWA

Чтобы система выглядела как нативное мобильное приложение:

1.  **На iPhone (Safari):** Откройте ссылку дашборда -> Нажмите кнопку "Поделиться" (квадрат со стрелкой) -> Выберите "На экран «Домой»".
2.  **На Android (Chrome):** Откройте ссылку -> Нажмите на три точки в углу -> "Установить приложение".

Теперь NeuroSupply всегда под рукой на рабочем столе телефона.
