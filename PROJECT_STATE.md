# PROJECT STATE - NeuroSupply v2.4.0 (Pure Web)
**Status:** Stable / Commercial Ready
**Architecture:** Unified Web (No Google Sheets dependency for settings)
**Last Update:** 2026-03-15

## 📡 Текущий статус
Система NeuroSupply переведена на единую Web-платформу и оптимизирована для **коммерческой эксплуатации**. Все функции, ранее зависевшие от Telegram-бота и Google Sheets, теперь интегрированы в Dashboard (Next.js) и Mini App (Vue 3).

### ✅ Готовые функции
- **Унифицированная авторизация**: JWT-защищенный вход для менеджеров и поваров.
- **AI-движок v2.1**: Прямой расчет потребности на основе техкарт и прогнозов из PostgreSQL. **Обновлен для обучения на реальных данных потребления.**
- **Pure Web Settings**: Управление параметрами расчета (Safety Stock, Days in Transit) напрямую через Dashboard.
- **Монетизация (NeuroCredits)**: Система учета потребления ИИ-ресурсов.
- **Синхронизация с iiko**: Автоматический импорт остатков и справочников через Cloud и Resto API (минуя Sheets).
- **Кросс-навигация**: Бесшовный переход между операционным приложением (`/`) и панелью управления (`/dashboard`) для менеджеров. Добавлена кнопка быстрого переключения в главном меню.
- **Очистка Legacy**: Полное удаление зависимостей от Telegram и Google Sheets для операционной логики.
- **Производительность**: Внедрены индексы для ускорения поиска аномалий и работы с большими объемами данных.
- **Экспорт отчетности**: Генерация Excel-заявок напрямую из браузера.
- **PWA**: Mini App поддерживает установку как приложение для работы на складах.

### ⚠️ Известные проблемы
- **iiko Integration**: Требуется стабильное подключение к серверу iiko для корректного отображения остатков в реальном времени.

### 🛠 Ближайшие планы
- **Расширение AI**: Добавление анализа внешних факторов (погода, праздники) в алгоритм прогнозирования.
- **Интеграция с Procob**: Автоматизация оправки заказов напрямую в Procob API.
- **Мобильное приложение**: Полноценный оффлайн-режим для пересчета остатков на складах без связи.
