# NeuroSupply: Интеллектуальное управление закупками (v2.4.0)

Это репозиторий системы **NeuroSupply**, созданной для автоматизации процесса формирования заказов продуктов на основе планов продаж и техкарт.

- **Бизнес-логика**: [BUSINESS_LOGIC_GUIDE.md](./BUSINESS_LOGIC_GUIDE.md) — Описание процессов (v2.4.0).
- **Гайд для презентации**: [PRESENTATION_GUIDE.md](./PRESENTATION_GUIDE.md) — Пошаговое руководство.
- **Статус проекта**: [PROJECT_STATE.md](./PROJECT_STATE.md) — Технический аудит и Pure Web архитектура.

## 🚀 Как начать работу? (Для собственника)

1. **Авторизация**: Вход в Dashboard или Mini App с вашим корпоративным аккаунтом.
2. **Настройка параметров**: Во вкладке "Настройки" Dashboard укажите коэффициенты страхового запаса и дни в пути для каждого ресторана.
3. **Синхронизация**: При необходимости нажмите кнопку "Синхронизировать", чтобы обновить данные об остатках из iiko.
4. **Контроль заказов**: Проверяйте подтвержденные поварами заявки и выгружайте их в Excel для поставщиков.

## 🛠 Технический статус (Обновление v2.4.0)
- **Архитектура**: Pure Web (Settings & Data in DB).
- **Синхронизация**: Прямая (iiko Cloud/Resto).
- **Готовность**: Система полностью верифицирована (End-to-End Onboarding), стабильна и готова к коммерческой эксплуатации.
