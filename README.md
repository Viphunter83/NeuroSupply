# NeuroSupply - Автономная Система Управления Запасами

## Обзор
NeuroSupply - это интеллектуальная система для автоматизации управления запасами ресторанов. Она интегрируется с POS-системой (iikoCloud), обрабатывает данные о продажах и остатках, рассчитывает потребности в закупках и позволяет управляющим подтверждать заказы через Telegram-бота.

## Основной Стек Технологий
*   **Backend**: Python 3.11, FastAPI
*   **Database**: PostgreSQL 16 (AsyncAlchemy, Alembic)
*   **Cache & Queue**: Redis, TaskIQ
*   **Bot**: Aiogram 3.x
*   **Infrastructure**: Docker, Docker Compose

## Структура Проекта
```
src/
├── api/          # REST API эндпоинты
├── bot/          # Логика Telegram бота
├── core/         # Конфигурация и настройки
├── db/           # Модели БД и миграции
├── schemas/      # Pydantic схемы
├── scripts/      # Скрипты (импорт данных и т.д.)
├── services/     # Бизнес-логика (Iiko, Расчеты)
└── main.py       # Точка входа API
```

## Быстрый Старт (Docker)
1.  Создайте `.env` файл из `.env.example`.
2.  Запустите контейнеры:
    ```bash
    docker-compose up -d --build
    ```
3.  API доступно по адресу: `http://localhost:8000/docs`
